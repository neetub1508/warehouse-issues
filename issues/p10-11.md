## Scope

### Data model (`V560090`)

- **`whm_item_planning_params`** — item × site: `item_id`, `warehouse_id`, `planning_method` (`MRP`/`REORDER_POINT`/
  `NONE`), `procurement_type` (`MAKE`/`BUY`), `lot_sizing_rule`, `fixed_lot_quantity`, `min_lot_quantity`,
  `max_lot_quantity`, `rounding_multiple`, `safety_stock_quantity DECIMAL(18,4)`, `safety_lead_time_days`,
  `manufacturing_lead_time_days`, `purchase_lead_time_days` (nullable), `planning_time_fence_days`,
  `qc_lead_time_days`, `default_bom_alternative_no`, `is_active`. uk `(item_id, warehouse_id)`. Composite FKs to the
  code lists; no CHECK on vocabularies.
- **`whm_demand_plans`** — `plan_code`, `name`, `warehouse_id`, `bucket` (`WEEK`/`MONTH`), `consumption_mode`
  (`MAX_OF_FORECAST_AND_ORDERS`/`FORECAST_PLUS_ORDERS`), `status` (`DRAFT`/`ACTIVE`/`ARCHIVED`), `valid_from/to DATE`.
- **`whm_demand_plan_lines`** — `plan_id`, `item_id`, `period_start DATE`, `quantity DECIMAL(18,4)`,
  uk `(plan_id, item_id, period_start)`.

### Rules

- **Planning parameters** (`FR-662`): `REORDER_POINT` is left to core replenishment (MRP skips the item);
  `NONE` excludes it. **Purchase lead-time fallback**: own value → priority-1 `whb_item_supplier_sources.lead_time_days`
  → `whb_item_site_settings.lead_time_days`; the resolved value and its source are shown read-only. `FIXED` needs
  `fixed_lot_quantity`; `MIN_MAX` needs min ≤ max; rounding multiple > 0. `MAKE` without an approved BOM is allowed
  here and raises `NO_BOM` in MRP (`p10-12`).
- **Demand plans** (`FR-663`): item × bucket quantities; `period_start` aligned to the bucket (Monday / first of
  month — refused otherwise); **one `ACTIVE` plan per site at a time** (activate archives nothing silently —
  `409 ACTIVE_PLAN_EXISTS` names the current one; the planner archives it first). Default consumption mode
  `MAX_OF_FORECAST_AND_ORDERS` (orders consume forecast in the bucket). Lines are editable in `DRAFT` **and**
  `ACTIVE` (`whm_demand_plans:edit`), refused `409 MRP_RUN_IN_PROGRESS` while a run of the site is `QUEUED`/`RUNNING`;
  `ARCHIVED` is read-only (MD-40, R29 F26 — aligned with `MRP-T2-02`).
- **Bucket grid editor + import**: the lines editor is an item × period grid served by the backend; bulk upload via
  the `ImportButton` pattern (Service Vehicle), validated server-side.
- Caches `statistics.whmItemPlanningParam`, `statistics.whmDemandPlan` registered and evicted.
