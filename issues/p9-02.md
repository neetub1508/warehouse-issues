## Scope

### Data model (`V550010`)
- `wht_supplier_profiles`, `wht_customer_profiles` — columns per the contract §0. `counterparty_id` ↓
  `whb_counterparties`, `company_id` ↓ `whb_companies`; `uk (company_id, counterparty_id)` per table.
  `default_ship_to_address_id` ↓ `whb_counterparty_addresses`; `default_dispatch_warehouse_id` ↓ `whb_warehouses`.
  `udyam_registration_no` `VARCHAR(19)`; payment terms are **recorded only** — no due-date, no payment column.
- `wht_approved_vendor_items` — `item_id` ↓ `whb_items` xor `item_category_id` ↓ `whb_item_categories`
  (CHECK on the xor is allowed: structural, not a vocabulary); `EXCLUDE USING gist` on (company, coalesce(item,
  category), supplier, daterange) for approved rows (`btree_gist` is base's, asserted by `V550000` — do
  not `CREATE EXTENSION` here). `approval_state` (`PENDING`/`APPROVED`/`REJECTED`), `approval_request_id`,
  `pending_change` (the held maker change, `TCE-T1-04`).
- `wht_customer_item_refs` — uk (company, customer, item, drawing_revision).
- `wht_terms_templates` (company, `document_type_code`, name) + `wht_terms_template_versions` (version_no,
  body TEXT, effective_from, is_current); documents freeze the version id.

### Seeds (`V550011`) — owning-module guard on every row (`RL-003`; abort if a row with the same code has another `owning_module`)
- Code lists (`whb_code_lists` + `whb_code_list_values`, `owning_module = 'warehouse-trade'`):
  `trade_msme_category`, `trade_customer_category`, `trade_block_reason`, `trade_avl_status`,
  `trade_part_approval_status`, `trade_payment_terms`, `trade_delivery_terms`, `trade_freight_terms`,
  `trade_priority`, `trade_charge_type`, `trade_award_reason`, `trade_limited_source_reason`,
  `trade_decline_reason`, `trade_loss_reason`, `trade_regret_reason`, `trade_enquiry_source`,
  `trade_short_close_reason`, `trade_cancel_reason`, `trade_amendment_reason`, `trade_return_reason`,
  `trade_return_intent`, `trade_evaluation_grade`. Values in en; labels in en / fr / hi i18n through the
  module's `registryLabel` helper copy (`wht…VocabularyOptions.ts`, one copy, never cross-imported).
- `whb_document_types` + default `whb_number_series` per company (`YEARLY`, `is_gapless = false`):
  `PR`, `RFQ`, `VQ`, `CS`, `PRC`, `PO`, `PA`, `ENQ`, `SQ`, `PL`, `SRC`, `SO`, `SRA`. **No release or
  amendment series** (FR-547): releases are `<order>-Rnn` / `-Dnn` and amendments `<order>-Ann` from a
  per-order counter. (Per `OD-30` the trade `PO` / `PA` number is the supplier-facing one and is stored on the core PO as `source_document_ref`; core keeps its own `po_number`.)
- `whb_source_systems` is **not** seeded here — `V551000` (p9-01) owns the `WAREHOUSE_TRADE` row.
- `wh_print_templates` template kinds (code-list values of core's `template_kind_list`, owned by trade):
  the nine kinds of FR-615. **Each consuming task seeds a minimal default template for its own kinds**
  (p9-04 `PURCHASE_REQUISITION`, p9-05 `RFQ` / `COMPARATIVE_STATEMENT`, p9-07 `PURCHASE_ORDER` /
  `SCHEDULE_RELEASE`, p9-08 `CUSTOMER_QUOTATION` / `REGRET_LETTER`, p9-10 `SALES_ORDER_ACK`, p9-13
  `SALES_RETURN_AUTHORISATION`), so no scenario waits for p9-14; p9-14 adds the final layouts as new versions.

- `TCE-GRD-01`…`-03`; block / unblock is an approval request of type `PROFILE_BLOCK`, and every AVL
  entry or status / date change is an approval request of type `AVL` held in `pending_change` until
  approved (`TCE-T1-04`) — both **need p9-03**; until it lands the Block action and AVL maintenance are
  hidden, not bypassed.

- AVL enforcement setting `warehouse.trade.avl.enforcement` (`WARN`/`REFUSE`, default `REFUSE`) seeded in
  admin settings with the other trade settings listed in the EPIC.
- `AvlService.check(company, supplier, item, date)` and `CustomerPartApprovalService.check(...)` are
  published beans for p9-05/06/07/08/09.

## Traps
- **No second master.** No name, address, GSTIN or contact column on a profile — they are the
  counterparty's (`p1-08`). A profile row without the role link is refused, not auto-linked.
- **Payment terms are a label**, never a due-date calculator (accounting deferred).
- The Udyam pattern is uppercase; trim and upper-case before validating.
- `filter_definitions` is the table name (not `grid_filter_definitions`).
- Customer item refs are reference data for sales lines; do not put the customer part number on `whb_item_external_refs`.
