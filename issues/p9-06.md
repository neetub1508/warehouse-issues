## Scope
- Tables per contract §0. Price rows carry denormalised `company_id`, `counterparty_id`, `item_id`,
  `uom_code` (set by trigger from header / line) and `is_effective` (true once the contract or its
  amendment is approved) so the `EXCLUDE … WHERE (is_effective)` can be declared (`btree_gist` is base's,
  asserted by `V550000`).
- **One shared amendment engine** for all three kinds (`TRC-T1-05`, `-05a`): `wht_rate_contract_amendments`
  (`contract_kind` `PRC` / `SRC` / `PL`) + `wht_rate_contract_amendment_changes` (change kinds incl.
  `TERMINATE`), approval doc types `PRC_AMENDMENT` / `SRC_AMENDMENT` / `PRICE_LIST_AMENDMENT`
  (FR-548; approve verbs per `TAM` §0.1), number `<contract>-Ann` (no series). Price revision, validity
  extension, add line, ceiling change, terms and **termination** all go through it; drafted with
  `:amend`, submitted with `:submit`, approved with `:approve`.
- **Dated termination and supersession** (`TRD-15`): an approved termination sets `terminates_on` +
  `termination_reason_code` and closes the price rows on that date; supersession sets `superseded_on` /
  `superseded_by_id`; `TradeContractJob` moves the header to `TERMINATED` / `SUPERSEDED` **on** the date
  (`TRC-T3-04`). Lines resolving `AT_RELEASE` after the date refuse with the contract's end (`WH-SC-571`).
- **Price lists**: categories through junction `wht_price_list_categories`; `priority` (integer ≥ 1,
  1 = first) decides between overlapping lists for one customer; equal-priority overlaps for one item
  are refused at approval (`TRC-GRD-05`, `TRC-T4-04`, `WH-SC-590`).
- `PurchasePriceResolutionService` and `SalesPriceResolutionService` (`TRC-T4-02`, `-04`) — the single
  entry points every PR / CS / PO / quotation / SO line uses; unit-test matrix covering slab boundaries,
  UoM conversion (factor frozen on the caller's line), currency mismatch, expiry, termination, floor.
- `RateContractConsumptionService` (`TRC-T4-01`) with row lock on the contract line.
- CSV import of price rows (dry-run → apply; validate persists nothing — backend-asserted).
- `TradeContractJob` (`TRC-T3-01`…`-04`), setting `warehouse.trade.contract.expiry_alert_days` (30).
- Permissions / menus (*Purchasing — Orders*, *Sales — Pre-sales*, *Sales — Orders*) / grids / caches.
