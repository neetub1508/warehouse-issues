## Traps

- **⚠ The failure this task prevents has already happened once in this monorepo.** `G-025`: the previous
  attempt put suppliers in a supply-chain module and produced **84 FK references from warehouse into
  `scc_*`**, several to tables that never existed, with a designated owner (`SccCompany`) that was
  **never built** — only an orphan `scc_company_id` column with no FK
  (`SCC_MODULE_ISSUES_ANALYSIS.md` §4.4). *"84 FKs is not a seam."*
- **The ghost is still in the tree.** `grep -rl "scc_"` over `classic` (excluding `node_modules`) returns
  exactly **two files, both comments**: `platform/…/V663__Grant_branch_admin_branch_safe_permissions.sql:18`
  and `platform/…/util/CountryStateRegistry.java:32` — the latter a Javadoc line still asserting *"the
  platform stores them in `scc_warehouses.state` and friends"*, **a reference to a table that does not
  exist here**. Re-run the grep; if the comment is still there, note it. Do not "fix" it in this task.
- **`whb_counterparties` must not acquire payment terms or credit limits** (`G-030`). `asset_vendors` has
  `payment_term_id`, `credit_limit`, `currency`, `rating` (`assets/…/V60056:3-38`) — *"right for a
  vertical, wrong for a stock ledger's counterparty. Once base has a credit limit, base has an opinion
  about AR, and the accounting seam leaks."* The review rule is: **any new column on
  `whb_counterparties` must be justified as *needed to post a movement*.**
- **Extraction is expensive **and** premature is worse.** *"Until then, speculative; after then,
  overdue."* Do not soften the trigger into "when it feels like time" — the specificity is the whole
  value.
- **Do not conflate this with `OD-3`.** A shared party master is not multi-tenancy; `grep -ril "tenant"
  platform/backend/src/main/java` → **0 files**, and the two are argued separately.
