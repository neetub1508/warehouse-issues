## Rules

- **Byte-identical behaviour.** The picker SQL is copied, not rewritten, and keeps the same ordering, `includeCode` semantics and DTO. The hash
  produces the same hex for the same input. Add one unit test asserting `sha256Hex("abc")` =
  `ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad`.
- **Constructor injection** in the three base services switches from `WhbCategoryStockingOwnershipQueryService` to
  `WhbItemCategoryQueryService`. No field injection.
- `WhbItemCategoryQueryService` keeps `@Transactional(readOnly = true)` on the moved method.
