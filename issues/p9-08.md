## Scope
- Tables per contract §0 (`V550070`).
- Enquiry → quotation → versions → send → won / lost / expired; regret with `REGRET_LETTER`.
- **Per-line outcomes** (`line_outcome` on enquiry and quotation lines): a win records each line `WON` or
  `LOST` (loss reason, competitor and price per lost line), and only won lines reach the SO
  (`TSQ-T1-09`, `TSQ-T4-02`); the enquiry line follows (`OPEN` → `QUOTED` → `WON` / `LOST`; `REGRETTED`).
- **An `EXPIRED` latest version is still revisable, winnable with the customer's PO date ≤ `valid_until`,
  and losable** (`TSQ-T1-08`…`-10`, `TSQ-GRD-05`; `WH-SC-582`).
- Quotation charges (`wht_customer_quotation_charges`, the twin of `wht_vendor_quotation_charges`), carried
  to `wht_so_charges` of the won SO.
- Pricing through `SalesPriceResolutionService` (p9-06); conditions `below_floor_price`, `discount_over_pct`
  (setting `warehouse.trade.sales.discount_approval_pct`); `TradeApprovable` `SQ`. The zero-level `SQ` rule
  (`EXACT`, no condition) is **seeded by p9-03**, not here — a quotation carrying a condition routes to an
  install-defined rule or is refused (`WH-SC-585`).
- Part approval gate (p9-02 `CustomerPartApprovalService`).
- Win target drafts (`TSQ-T4-02`): SO types need p9-09, sales RC needs p9-06; unavailable targets hidden.
- Version compare (backend diff).
- WS-300 report (backend aggregation; export allowed).
- `TradeSalesJob` (`TSQ-T3-01`…`-03`; kinds `TRADE_QUOTE_BY`, `TRADE_QUOTATION_EXPIRED`,
  `TRADE_QUOTATION_FOLLOWUP`), settings `warehouse.trade.quotation.validity_days` (30),
  `quotation.followup_days` (7).
- Prints `CUSTOMER_QUOTATION`, `REGRET_LETTER`: this task seeds their minimal default templates (FR-615),
  so sending a quotation works before p9-14, which adds final layouts.
- **Lost sale for stock** (`FR-680`, `D-17` item 4, R30 `CP-GA-003`; `TSQ-T4-05`): a line regretted or recorded
  `LOST` with a reason in `warehouse.trade.sales.lost_sale_reason_codes` calls the registered core port
  **`WhLostSalePort.captureLostSale(PortEnvelope, …)`** (FRD-STORES R.2; FRD-TRADE §12c `CN-11`; R31 F-TR-011 — never
  the core service directly), key `WHT_SALES_ENQUIRY:<id>:LOST_SALE_CAPTURE:<line id>` /
  `WHT_CUSTOMER_QUOTATION:<id>:LOST_SALE_CAPTURE:<line id>`, in the same transaction and stores `lost_sale_log_id`
  on the quotation line and its enquiry line (`V550070`). The site is the enquiry's or the **quotation's own
  `dispatch_warehouse_id`** (NOT NULL, defaulted from the enquiry, else the customer profile's default dispatch
  site — a quotation may have no enquiry; R31 F-TR-009). A not-catalogued enquiry line (no `item_id`) can be
  **regretted** — that is the *not catalogued* lost sale — but not quoted (`TSQ-GRD-04`; R31 F-TR-010).
  `V551080` seeds the values `NO_STOCK` and `LEAD_TIME_NOT_MET` into the code lists `trade_regret_reason` and
  `trade_loss_reason` and as `whb_reason_codes` rows of context `TRADE_ORDER_CLOSE` (the SO cancel / short-close
  reasons, FR-546) (`ON CONFLICT DO NOTHING`, RL-003), the core reason code `TRADE_STOCK_NOT_AVAILABLE` (context `SHORT_PICK`,
  `affects_demand_history = true`, `owning_module = 'warehouse-trade'`) and the setting (default
  `NO_STOCK,LEAD_TIME_NOT_MET`). Trade is now the only producer of core `FR-257` / `WH-SC-283`; the dealer and
  services adapters that produced it are removed (`D-16`).
- **Master-merge open-document provider** (R30 `CP-GA-004`, `WH-SC-330`): a `WhbMasterMergeOpenDocumentProvider`
  bean for enquiries and quotations not yet `WON` / `LOST` / `REGRETTED` / `CANCELLED`, naming the customer and
  item, so an item or counterparty merge with an open one is refused (copy `WhPurchaseOrderMasterMergeDocumentProvider`).
- Permissions / menus (*Sales — Pre-sales*) / grids / scopes / caches (`V551080`, `V551081`). The sales-executive
  bundle, which records the outcome and so calls the lost-sale port, gets core `warehouse:orders:port` and
  `wh_insufficient_stock_log:view:branch` (`POS-T1-40` needs `wh_insufficient_stock_log:create`, granted through the
  port's dependencies; FR-617, R31 F-SR-004).
