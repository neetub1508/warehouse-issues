### Behaviour
- **Authorisation (`FR-697`, `QIC-GRD-01`).** With `inspector_authorisation_required = true`, *Start*, *Record results* and *Complete* need a current `INSPECTOR` (or `APPROVER`) authorisation matching the inspection's site, stage and **any** category of the item (`whb_item_category_assignments`), valid on the site-local today; otherwise `403 INSPECTOR_NOT_AUTHORISED` naming site, stage and item category. *Disposition* and *Approve result* need an `APPROVER` authorisation for the same scope (`403 INSPECTION_APPROVER_NOT_AUTHORISED`). The permission check runs first; the authorisation is an additional record-level guard, never a substitute for the verb.
- **Segregation (`FR-698`, `QIC-GRD-02`, `-03`).** `GOODS_RECEIPT` source: the user who created or posted the GRN (`wh_goods_receipts.created_by`, `posted_by`) cannot record results or complete — `403 INSPECTOR_IS_RECEIVER` — unless `inspector_may_be_receiver`. Production sources: the resolver's new default method `producedByUserIds(sourceDocumentId, sourceLineId)` (empty by default; MFG returns the operation-confirmation and receipt posters) — a match is refused `403 INSPECTOR_IS_PRODUCER` unless `inspector_may_be_producer`. `STORE_RETURN` source: the return's submitter is refused `403 INSPECTOR_IS_RETURNER`. Each refusal is audited with the user and the source.
- **Result approval (`FR-699`, `QIC-T1-03`…`-05`).** On *Complete*, `result_approval_status` = `PENDING` when the mode is `ALL`, or `REJECT_ONLY` and any line carries a reject outcome/defective count > Ac; else `NOT_REQUIRED`. While `PENDING`: Disposition is refused `409 RESULT_APPROVAL_PENDING`; *Approve result* (`:approve_result`, `APPROVER` authorisation, ≠ every user who recorded a result — `403 RESULT_SELF_APPROVAL`) sets `APPROVED`; *Return* (reason mandatory) sets `RETURNED` and reopens the results for the inspector (the inspection is *in progress* again; `RQP-UNR-04` still forbids editing a completed **verdict**, so Return clears `lot_verdict` and the inspector re-completes). Approval is a fact on the inspection, audited; the approved inspection is then dispositioned as today.
- **Mobile:** none (`D-20` item 5).

## Traps
- **"Any category of the item"** — items carry several category assignments (`RG-005`); matching only the stocking category refuses authorised inspectors.
- **Segregation reads the GRN's own audit columns**, never the session's unloader — the person accountable for the GRN is its creator and poster.
- **Return is not an edit of a completed verdict** (`RQP-UNR-04`): it clears the verdict and reopens results with an audit row; the old values stay in history.
- The user display in the grid uses the platform helper (`PlatformUserDisplaySql` / `userDisplayUtils`), never concatenated fields.
