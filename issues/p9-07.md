## Scope
- Tables `wht_purchase_orders`, `wht_purchase_order_lines`, `wht_po_schedule_lines`, `wht_po_releases`,
  `wht_po_release_lines`, `wht_po_charges` (`V550060`); `core_po_id` / `core_po_line_id` ↓ `wh_purchase_orders`
  / lines (FK down).
- Types and type rules (`TPO-GRD-02`, `-04`); `po_type` immutable after submit. **FIXED needs no release**
  on either side (`TRD-12`): its schedule goes to core `FIRM` at approval and is received directly.
- `deliver_to_location_id`, `receipt_cutoff_date` (DATE, null or ≥ `valid_to`, `TPO-GRD-16`) passed to the
  port so core refuses receipts after the cut-off (`WH-SC-572`).
- Pricing through `PurchasePriceResolutionService` (p9-06); `price_source`; `manual_rate` condition.
- MSME acknowledgement (`TPO-GRD-01`, FR-542); AVL check (p9-02).
- Approval `TradeApprovable` `PO`, `PO_RELEASE` and `PO_CANCEL`; `onApproved` calls the **`p8-01` port** in
  the same transaction (`TPO-T4-01`, `-02`); refusal relay (`TPO-T4-03`). **Release ladder**: `PO_RELEASE`
  is approved by the seeded zero-level `EXACT` rule (p9-03) unless the release carries `open_unbounded`
  (OPEN PO with no ceiling value) or `release_price_manual`, which need an install rule with levels
  (FR-580). Release cancel before approval (`TPO-T1-10b`) and after it for the unreceived part
  (`TPO-T1-10c`, `TPO-T4-09`); a release closes on core events (`TPO-T1-12`, `TPO-T4-11`).
- **Port calls use the registry exactly** (FRD-STORES R.2; FRD-TRADE §12a): envelope
  `PortEnvelope('warehouse-trade', key, actingUserId)` with `actingUserId` = the last approver (the
  submitter when approved by `SYSTEM`); keys `WHT_PURCHASE_ORDER:<poId>:<operation>:<sequence>` with
  operations `PO_CREATE`, `PO_RELEASE` (sequence = release number), `PO_AMEND`, `PO_CANCEL_SCHEDULE`,
  `PO_CLOSE_LINE`, `PO_CLOSE`, `PO_CANCEL` (`TPO-GRD-12`). `releaseSchedule` uses `firm(scheduleLineId)`
  for a whole BLANKET line at the line rate and `add(poLineId, FIRM, date, qty, unitPrice)` otherwise,
  reducing the `FORECAST` remainder by `amendOrder` `scheduleChanges` (`TPO-T4-02`).
- **Port authority** (`TRD-13`): `V551070` grants core `warehouse:orders:port` to the purchase-manager
  (approver) and buyer bundles; a level member without it is refused `403 PORT_AUTHORITY_REQUIRED` at
  approval (`WH-SC-568`), and the approval rolls back.
- Numbering per `OD-30`: the **trade** number is the supplier-facing one — FIXED/OPEN from series `PO`, BLANKET from `PA`,
  issued at submit, printed, and passed to the port as `sourceDocumentRef` (core keeps its own internal `po_number`;
  `p8-01` takes no number parameter); releases `<po_number>-Rnn`.
- Release proposal job `TradeReleaseProposalJob` (`TPO-T3-01`, `-06` release overdue →
  `TRADE_RELEASE_OVERDUE`), settings `warehouse.trade.release_horizon_days` (7),
  `warehouse.trade.firm_zone_days` (14); proposals are `PROPOSED`, never released (`TRD-11`).
- Cancel (`TPO-T1-05`, `TPO-GRD-09`): before approval directly; **after approval an approval request
  `PO_CANCEL`** (seeded zero-level, p9-03) whose approval calls `WhPurchaseOrderPort.cancelOrder` (key
  `…:PO_CANCEL:1`) in the same transaction (`TPO-T1-05a`); refused once anything is received or on an open
  gate entry (`getReceiptPosition`, `WH-SC-576`). Register trade's `PurchaseOrderChangeGuard` bean
  (`POS-GRD-08`) refusing core-screen `EDIT`, `RELEASE_SCHEDULE`, `SUBMIT`, `APPROVE`, `RETURN`, `CANCEL`,
  `CLOSE`, `CLOSE_LINE` on trade-created core POs with `409 PO_OWNED_BY_SOURCE_MODULE` (`OD-39`).
- Subscribe to `WH_PO_SCHEDULE_LINE_RECEIVED`, `WH_PO_LINE_RECEIVED`, `WH_PO_AMENDED`, `WH_PO_CLOSED`,
  `WH_PO_CANCELLED` (`TPO-T4-11`).
- Read-only core tabs on WS-293 (`TPO-T4-04`): gate entries (`p8-03`), GRNs with bill no / date / billed qty
  (`p8-04`), QC (`p8-06`), MRNs (`p8-08`), supplier returns and claims — via core query beans; fulfilment derived.
- PR allocations from the workbench (p9-04) and award targets (p9-05) land here.
- Print `PURCHASE_ORDER`, `SCHEDULE_RELEASE`: this task seeds their minimal default templates (FR-615); p9-14 adds final layouts.
- Permissions / menus / grids / scopes / caches (`V551070`, `V551071`).
