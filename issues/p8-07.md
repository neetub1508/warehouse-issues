## Scope

R27 `RM-012`: a reject or RTV disposition moves stock to `REJECTED`/`BLOCKED` (`V510016:61-64`); the
supplier return (`V510020`, `DRAFT → APPROVED → PICKED → DISPATCHED → CLOSED`, reason `QUALITY_REJECTED`)
must be keyed by hand; there is no link from the return to the inspection — only a status default from the
latest dispositioned inspection (`WhSupplierReturnValidationService.java:124`). `FR-139` refuses an
automatic return. `RN-031`: add an explicit action, manual and maker/checker.

- **ALTER `wh_supplier_return_lines`**: `origin_inspection_line_id → wh_quality_inspection_lines` (nullable); idx.
- No new status, no new table.

### Seeds — `V511406`

### Behaviour
- `POST /warehouse/inbound/quality-inspections/{id}/raise-supplier-return` → `WhQualityInspectionService.raiseSupplierReturn(id, actorId)` → `WhSupplierReturnService.create(...)` (`:205`) with the pre-fill of `IIS-T1-10`; returns the new return id; the UI opens WS-084 on it.
- Quantity per line = Σ dispositioned `REJECT`/`RTV` on the inspection line − Σ quantity on live (`≠ CANCELLED`) return lines with that `origin_inspection_line_id`.
- **FRD amendment recorded:** `FR-139`'s *"QC never raises a supplier return automatically"* now reads *"…automatically; an explicit, manual action may create a `DRAFT` return (`FR-526`)"* — SPINE edits the main FRD row from `FRD-STORES.md` §6.6.
