## Scope

R27 `RM-012`: a reject or RTV disposition moves stock to `REJECTED`/`BLOCKED` (`V510016:61-64`); the
supplier return (`V510020`, `DRAFT → APPROVED → PICKED → DISPATCHED → CLOSED`, reason `QUALITY_REJECTED`)
must be keyed by hand; there is no link from the return to the inspection — only a status default from the
latest dispositioned inspection (`WhSupplierReturnValidationService.java:124`). `FR-139` refuses an
automatic return. `RN-031`: add an explicit action, manual and maker/checker.
