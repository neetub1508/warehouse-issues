## Scope
- Tables per contract §0 (`V550110`); seed task type `TRADE_AVL_REVIEW` (`TCE-OPEN-01`) under the owning-module guard.
- Metric calculators per the catalogue, reading core receipt facts (`p6-05`), QC (`p8-06`), shipments,
  RMAs (FK down / core query beans) and trade documents; numerator and denominator stored.
- **OTIF definitions, both sides** (contract metric catalogue): a committed schedule line counts on time
  when received / shipped on or before its date (site tz) **and** in full within the line's
  under-tolerance. Purchase: FIXED lines and released OPEN / BLANKET quantities only — a BLANKET line left
  unreleased past its date (`TPO-T3-06`) is our fault and is excluded. Sales: unreleased lines count
  (`TSO-T3-06`, the release is ours to make).
- **Customer rating metrics**: `DELIVERY_OTIF`, `RETURN_RATE` (SRA quantities, p9-13),
  `SCHEDULE_VOLATILITY` (firm-zone schedule changes from `TOA-T4-06`; firm zone =
  `warehouse.trade.sales.firm_zone_days`, default 14), `ENQUIRY_CONVERSION` (`WH-SC-592`).
- Run → publish (maker ≠ checker) → supersede; `latest_grade_code` on profiles; review task.
- Grade shown on CS (p9-05), PO, SO, AVL, profiles.
- `TradeEvaluationJob` monthly drafts; setting `warehouse.trade.evaluation.review_grade` (`D`).
- This task **is** the supply-chain scorecard `p6-05` defers to (`TRD-05`); core still stores none.
