## Scope

- **`whb_devices`** (`V500062`, `DATA-MODEL.md` §7.2 WHB-62) — device inventory and assignment.
- **Device-bound long sessions.** An operator will not type a password every fifteen minutes with
  gloves on, so the session is bound to a registered device and has a long expiry (`S-088`).
- **Fast shared-device sign-in** — twelve guns on a two-shift site are shared, not personal.
- **Session handover at shift change** that **transfers the open tasks rather than orphaning them**
  (`WH-SC-231`). A handover that leaves eleven `STARTED` tasks pointing at a departed operator is
  what makes the exception console (`P3-02`) fill up with work that was actually done.
- **Remote session kill** on a lost gun.
- `whb_stock_movements.device_id` and `actor_type = DEVICE` are **v1 columns** (`IRREVERSIBLE.md`
  `IRR-48`); this task is what starts populating them honestly.

## Traps

- **The platform's existing device registration is a push-notification token, not a device.**
  `DeviceRegistrationRequest` registers an FCM/APNs token. Reusing it for a device-bound session
  means a session that dies when the token rotates. This is net-new (`S-088`, `PLATFORM-DEPENDENCIES.md`).
- **`lastSeenBefore` is a dropdown of named ages, not a date filter** — deliberately, so the mobile
  screen can carry it. `mobile/src/components/common/ListHeader.tsx:216` supports
  `type?: 'dropdown' | 'text'` and **no date type**; a date filter here would ship a web filter with
  no mobile counterpart and quietly break `D-13`.
- **Session handover must move the open tasks.** `WH-SC-231` asserts *"transfers the open tasks
  rather than orphaning them"*. A handover implemented as sign-out + sign-in leaves `whb_tasks` rows
  assigned to a user who has gone home.
- **Remote kill has to reach a device that is offline.** Kill is a server-side session revocation
  checked on the next request, not a push the lost gun must receive — a gun in a taxi has no network.
- **`whb_devices` is `warehouse-base`, not `warehouse`.** The ledger line references `device_id`, and
  base may not depend on app (`D-1`).
- **Register `dropdown.whbDevice` in `CacheConfiguration.java`** — an unregistered cache name throws
  `IllegalArgumentException` on the **first call**, not at startup (`CacheConfiguration.java:375-377`).

## Acceptance
- [ ] Twelve devices register, are assigned, and appear on WS-060 with `lastSeenAt` and `appVersion` populated from real sign-ins
- [ ] A device-bound session survives a shift without a re-password, and is revocable server-side
- [ ] Shift handover moves the outgoing operator's open `whb_tasks` rows to the incoming operator; none is left `STARTED` against a signed-out user
- [ ] The lost gun's session is killed from WS-060 and the next request it makes is refused, with the device offline at the moment of the kill
- [ ] `whb_stock_movements.device_id` is populated on every RF-posted movement
- [ ] The mobile counterpart is read-only and its `lastSeenBefore` filter is a dropdown
- [ ] **Scenarios** `WH-SC-231`
