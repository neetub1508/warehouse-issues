## Traps
- **A `CHECK` on an extensible value** (`D-10`): code-list rows referenced by composite FK `*_list` + code, never `CHECK`.
- **Seeding core-owned codes** trips core's own guard on the next core migration.
- **`MRP-` gapless** would serialise every run on one row lock for no statutory reason.
- **A movement type without its `*_REVERSAL` twin** leaves `L-3` correction impossible for that document.
- **`RN-045`** re-run on re-enable: `ON CONFLICT DO NOTHING` everywhere, and the guard must pass on a re-run.
- Label keys in en, fr **and** hi in this change — a missing `hi` key shows the raw code.
