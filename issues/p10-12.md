## Scope

### Data model (`V560100`, FRD §4)

- **`whm_mrp_runs`** — `run_number` (`MRP-`, not gapless), `warehouse_id`, `planning_date DATE`, `horizon_days`, `status`
  (`QUEUED`/`RUNNING`/`COMPLETED`/`FAILED`/`SUPERSEDED`), `job_run_id → whb_job_runs`, `started_at`, `finished_at`,
  counts, `error_message`, typed snapshot columns `demand_plan_id`, `include_forecast_schedule_lines`, `include_qc_hold_supply`, `params_note`.
- **`whm_mrp_proposals`** — `run_id`, `item_id`, `warehouse_id`, `proposal_type` (`MAKE`/`BUY`), `quantity`, `uom_code`,
  `need_date`, `start_date DATE`, `low_level_code`, `bom_id`, `status` (`OPEN`/`FIRMED`/`CONVERTED`/`DISMISSED`/
  `SUPERSEDED`), `firmed_by/at`, `converted_document_type/id/ref`, `dismiss_reason_code_id`.
- **`whm_mrp_pegging`** — `proposal_id`, `demand_type`, `demand_id`, `demand_line_id`, `demand_ref`, `quantity`, `parent_proposal_id`.
- **`whm_mrp_exceptions`** — `run_id`, `exception_code`, `item_id`, `document_type/id/ref`, `current_due_date`,
  `suggested_due_date` (not the reserved `current_date`, MD-27), `quantity`, `message`, `acknowledged_by/at`.

### Rules

- **Run** (`FR-664`, R-03): async `whb_job_runs` job, regenerative per site, **one run per site at a time** under an
  advisory lock (`409 MRP_RUN_IN_PROGRESS`); a scheduled run (`warehouse.manufacturing.mrp.schedule_cron`, null = manual; R31 `MRP-OPEN-08`) runs as **MFG's
  service principal** seeded by `p10-01` (never ADMIN, never a person; `STO-D20`) — `V561100` creates `whm_mrp_runs:run`
  and grants it to that principal, which already holds `warehouse:orders:port` and the `:view:all` site scope its
  `withdrawExternal` and port reads need (`MRP-T3-01`, `-04`; R31 F-MF-016, F-SR-004). Low-level codes from
  the `PRODUCTION` **and `SUBCONTRACT`** BOM graph (recursion → `RECURSIVE_BOM`; R31 F-MF-014). **Independent demand**: open demand-order lines incl. `FORECAST` lines,
  active demand plan after consumption, approved-not-issued MRQs **except** cost object `PRODUCTION_ORDER` (already
  dependent demand, MD-16). Safety stock is **not** a demand: the net rule alone restores projected stock to it
  (`MRP-N-09`; R29 F9 — `WH-SC-650` = 45). **Dependent**: components of open orders — less, for a `SUBCONTRACT` order, the open reconciliation quantity
  already at the job worker (`MRP-N-04`; R31 F-MF-003, `WH-SC-645`) — and of every **live** MAKE
  proposal — `OPEN` of this run and `FIRMED` of any run (R29 F10), with the BOM's process loss (R29 F29). **Supply**: allocatable on-hand of the **house owner only** (`L-14`; QC-held after
  `qc_lead_time_days` if `include_qc_hold_supply`), open PO schedule-line qty, open order remaining qty, `FIRMED`
  proposals, published-but-unordered MRP suggestions (`OD-44`, until a PO line references them or
  `mrp.suggestion_cover_days` elapse). Reservations whose holder is a counted demand are not subtracted twice.
- **Lot sizing, offsets, fences** (`FR-665`): daily net → `LOT_FOR_LOT`/`FIXED`/`MIN_MAX`/`PERIOD_WEEKLY`/`MONTHLY`,
  then min / max / rounding, every lot within the lot cap (largest multiple of the rounding multiple not above the
  maximum; `MRP-N-11`, R31 F-MF-020); start = need − (mfg or purchase lead time + safety lead time); component need offset by
  `lead_time_offset_days`; inside the planning time fence nothing new — `RESCHEDULE_IN`, `START_IN_PAST` when the start is really past, else
  `INSIDE_TIME_FENCE` (R31 `MRP-OPEN-03`; seeded by `p10-02`).
- **Proposals** (`FR-666`): pegged; **firm** (kept as supply across runs), **dismiss** (reason), **convert**: `MAKE` →
  `PLANNED` production order via `p10-05` — `SUBCONTRACT` when the proposal's BOM has usage `SUBCONTRACT`, the convert
  modal asking for the job worker and its `JOB_WORKER` location (`MRP-GRD-11`, `MRP-T4-03`; R31 F-MF-014) — with
  linked child orders (`parent_order_id`) for every **live** child proposal pegged to it, from any run, superseded
  ones excluded (`MRP-GRD-12`; R31 F-MF-015); converting an `OPEN` proposal firms it in the same transaction
  (`MRP-OPEN-04`); dismiss needs an `MRP_DISMISS` reason (`MRP-OPEN-05`);
  `BUY` → `WhReplenishmentSuggestionPort.publishExternal(PublishExternalCommand)` — envelope
  (`MRP_PROPOSAL:<proposalId>:SUGGESTION_PUBLISH:1`, the planner, who holds `warehouse:orders:port` from `V561100`),
  `origin = MRP`, `originRunId`, `suggestions[]` (`originDocumentId` = proposal, item, site, qty, UoM, `needDate`) —
  FRD-STORES registry R.2 (**SEAM-M3**, `OD-31` confirmed). Firm takes an `OPEN` proposal of the current run; convert
  and dismiss also take a `FIRMED` proposal of any run (`MRP-GRD-09`, R29 F1). With trade on, trade turns it into a PR (`p9-04`, FR-557); **with trade
  off, the core replenishment screen converts it to a draft core PO** (`OD-41`). `BUY` publishes only at convert; a new
  run supersedes `OPEN` proposals (none published) and keeps `FIRMED`/`CONVERTED`; a published suggestion no PO line
  references is supply for `suggestion_cover_days`; then the run calls `withdrawExternal` **before** planning and
  re-plans only the proposals answered `WITHDRAWN` — an `ALREADY_CONVERTED` one stays supply while
  `getSuggestionStatus(MRP, proposalId).conversionLive` (MD-24, R29 F13). **MFG never calls trade and never creates a PO.**
- **Exceptions** (`FR-667`): every `WHM_MRP_EXCEPTION` code, naming document and dates; acknowledged by the planner,
  never auto-applied. `DEMAND_CANCELLED` also raised from `p10-05`'s MTO link.

## R32 additions (PRD 2026-10-24)
- **MAKE rounding** (FR-830 is `p10-11`'s; `MRP-N-20`): a `MAKE` proposal of a batch-produced item is rounded up to a multiple of `standard_batch_size` after the lot-sizing rule.
- **Variant demand** (`MRP-N-21`, FR-781; R32 fix F-R32ME-021): demand for a variant item explodes through `BOM-T1-20` — its own `STANDARD` BOM, else the model's `BASE` BOM filtered to its applicable lines (option groups resolved); the model item is never planned `MAKE` from a `BASE` BOM. Nothing else changes.
