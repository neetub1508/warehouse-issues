### Rules
- **Ladder** `ECH-T1-01`…`-08`: create (no number on a draft) → items (link or create new `DRAFT` versions of `APPROVED` BOMs / routings and new revisions of released drawings; one live ECN per old version, `409 ECN_ITEM_IN_OTHER_ECN`) → *Compute impacts* and decisions **in `DRAFT`** (`ECH-T1-03`, `ECH-T4-01`) → submit (impacts recomputed, `409 ECN_IMPACTS_CHANGED` when new rows appeared, `422 ECN_IMPACT_UNDECIDED`, drawing items reviewed `ECH-GRD-12`; number `ECN-` gapless per company, yearly, **assigned here**; then the approval request locks the document, `DAP-GRD-07`; F-R32ME-012, -032) → approval through `p8-30` (`WHM_ECN`, verb `whm_ecns:approve`, `ecn.approval_levels`, default 2: Design Head, Plant Head — **(default — client Q-B6)**; submitter never approves `403 ECN_SELF_APPROVAL`; no user on two levels; append-only steps) → **implement** (one transaction: impacts recomputed under lock with `IMPLEMENT_DEFAULT` decisions for rows born during approval, `ECH-T4-07`; per object type BOM / routing `APPROVED`, drawing `RELEASED_FOR_PRODUCTION` with supersession and recall, implementer ≠ any drawing uploader `403 DRAWING_SELF_RELEASE` (F-R32ME-005); `effective_from_actual` = max(planned, today); predecessors end-dated; decisions executed, each result document id recorded) → `IMPLEMENTED`. Cancel from `DRAFT` / `SUBMITTED` / `APPROVED` (reason from `APPROVED`; F-R32ME-004).
- **Impact scope** (`ECH-T4-01`; F-R32ME-013): orders `PLANNED` / `APPROVED` / `RELEASED` / `IN_PROGRESS` matched on frozen `bom_id`, `base_bom_id`, `routing_id` or drawing revision; for a `DRAWING` item the where-used references (BOMs, routings, open PO / RFQ lines — `KEEP` / `NOTIFY`); old-part stock per bucket (allocatable, `QC_HOLD`, `SAMPLE`, at job workers, issued WIP). While the ECN is live, order create / release on an old version warns *version under ECN-…*.
- **`USE_UP`** (`ECH-T4-08`, `ECH-T3-03`, `ECH-T1-08`; F-R32ME-014): names `use_up_until` (`422 USE_UP_UNTIL_REQUIRED`); implement leaves the item `AWAITING_DEPLETION` with the old version effective; the nightly job tracks `use_up_remaining_quantity` and activates the new version (effective next day) at 0 or when `use_up_until` passes; *Activate now* by `whm_ecns:implement`.
- **Impact decisions** (`ECH-GRD-02`, `-03`): `PLANNED` / `APPROVED` orders `RE_EXPLODE` (FR-633 re-explode); `RELEASED` with nothing posted `RE_EXPLODE_UNSTARTED` or `KEEP` or `HOLD`; `IN_PROGRESS` `KEEP` or `HOLD` (hold reason `ENGINEERING_CHANGE`); old-part stock `USE_UP` / `REWORK` (a `PLANNED` rework order) / `SCRAP` (core scrap adjustment request with its approval) / `RETURN_TO_VENDOR` (core supplier-return draft) / `NONE`; purchase demand listed for the buyer. Approval refused while any row is undecided `422 ECN_IMPACT_UNDECIDED`.
- **Effectivity by date or by unit serial** (`ECH-EC-01`, `ECH-GRD-15`; F-R32ME-011): a `UNIT_SERIAL` ECN stamps `effective_from_unit_serial` on the new versions, item `AWAITING_UNIT`; release reserves the order's serial range in series order (FR-811, `p10-21`) — an order starting at or after the cut-over serial gets the new version (approved effective that day, predecessor end-dated), one straddling it is refused `409 ORDER_SPANS_ECN_CUTOVER` with the split quantity (`p10-05` release).
- **Governance** (FR-794, `ECH-GRD-11`): with `ecn_required_for_released_change` = `true` (default) the plain *New version* of an `APPROVED` BOM / routing and a new revision of a production-released drawing are refused `409 ECN_REQUIRED`, and such versions are approved only by implement (`409 VERSION_GOVERNED_BY_ECN`). First releases need no ECN.
- FRD-MFG `R-08` and `mfg-bom` §8 annotated *superseded by `D-20` item 1* (done in the design set).

## Traps
- **Approving the new versions one by one** — implement approves them together, or the effectivity of a multi-object change splits.
- **Re-exploding an order with postings** — only `RE_EXPLODE_UNSTARTED` on nothing posted; re-check under lock at implement (`409 ORDER_HAS_POSTINGS`).
- **Scrapping old-part stock directly** — a core scrap adjustment request with its own approval; the ECN only raises it.
- **Effective date as a timestamp** — it is a `DATE`.
- **Taking decisions after submit** — the approval request locks the document; decide in `DRAFT`, a return re-opens it.
- **Trusting the submit-time impact list** — implement recomputes; rows born during approval get defaults and are logged.
