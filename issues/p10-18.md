## Scope

### Data model (`V562040`)
`whm_drawings`, `whm_drawing_revisions`, `whm_drawing_issues` (DATA-MODEL §2.7.10, FR-795, FR-797). Files are platform documents linked to the revision (≥ 1, `422 DRAWING_FILE_REQUIRED`); partial unique index one `RELEASED_FOR_PRODUCTION` revision per drawing.

### Rules
- **Revision ladder** `ECH-T1-10`…`-14`; internal review by `whm_drawings:approve` (release for sample / return / reject); **production release** by *Request production release* (`whm_drawings:release`) through the approval engine — document type `WHM_DRAWING_RELEASE`, verb `whm_drawings:release`, `SINGLE_LEVEL` default (F-R32ME-007, -031); reviewer / releaser ≠ uploader (`403 DRAWING_SELF_RELEASE`); a `CUSTOMER` drawing, or one whose item has a marked demand line or an unapproved `blocks_production` sample request, is released for production only from `CUSTOMER_APPROVED` (`409 DRAWING_CUSTOMER_APPROVAL_REQUIRED`, `ECH-GRD-13`; F-R32ME-020); `SUPERSEDED` only by a later revision's production release — no manual supersede verb (F-R32ME-028); revision codes per `drawing.revision_scheme` (`ALPHA` default — **(default — client Q-S2)**); a production release while another revision is released goes through an ECN (FR-794) and supersedes the old one in the same transaction.
- **Print control** (FR-797): print kind `DRAWING_COPY` renders the revision with the watermark text `drawing.uncontrolled_watermark_text` unless the revision is `RELEASED_FOR_PRODUCTION` (or `RELEASED_FOR_SAMPLE` printed on a sample job card) **and** the user holds `whm_drawings:print_controlled`; every controlled copy writes `whm_drawing_issues` (issued to department / job worker / vendor); supersession lists open copies for recall.
- **Port** (cross-module change, declared in core): `ai.warehouse.port.engineering.DrawingRevisionPort` — `Optional<DrawingRef> currentReleased(UUID itemId)`, `DrawingRef revision(UUID drawingRevisionId)` (`drawingNumber`, `revisionCode`, `status`, `documentId`); optional bean (MFG); with MFG off trade keeps free-text drawing fields (FR-545). The trade fold wires PO / RFQ lines to it (its half).
- WS-320, WS-324, the traveller and the job card show the current released revision and flag a frozen reference that is superseded (`ECH-T4-04`).
