### Rules

- **Cost pool** (`FR-654`, `OD-40`, `MD-06`): value of issues + backflush into `VIRT-PRODUCTION` for the order
  − returns − value already absorbed, read from the `PRODUCTION` purpose (**SEAM-M1**).
- **Absorption service** (called by `p10-07` in the post transaction): a receipt absorbs its own backflush value fully
  plus the unabsorbed **issued** pool × (good main base qty ÷ remaining planned main base qty, cap 1); a final receipt
  absorbs all. By-product credit (qty × NRV) deducted first; **abnormal** scrap's proportional share → `VIRT-SCRAP`;
  the rest split over `MAIN` + `CO_PRODUCT` by cost share and quantity; unit costs written on the movement lines
  (`cost_basis = PRODUCTION_ACTUAL`). Rework order cost = carried value of reworked units + extras. **Non-own
  orders are never valued** (`L-14`).
- **Exact split** (`FR-655`): largest-remainder (`R-4`, `WhbCostLayerMath.split`), ties to lowest output `sequence`
  (`RF-009`); Σ output values = absorbed pool to the minor unit; a re-run reproduces it.
- **Close is a settlement** (`FR-656`): *Close* on a `COMPLETED` order computes the residual (late issues and returns
  accepted while `COMPLETED` — MD-14 —, rounding) and posts **one `PRODUCTION_SETTLEMENT` value-only movement** (`L-15`) onto output
  lots still on hand and `VIRT-COST_OF_SALES` for the consumed/shipped part (the `P2-28` landed-cost split).
  Residual share ≤ `close_variance_approval_percent` (default 5) → created and `POSTED` in one transaction; above →
  `DRAFT` awaiting a second user (`403 SETTLEMENT_SELF_APPROVAL`, MD-21) who approves or rejects; a `REJECTED`
  settlement frees the order to reopen or close again (MD-22). While a settlement is `DRAFT`/`APPROVED` the resolver
  refuses issues/returns and receipt reversal is refused (`409 ORDER_SETTLEMENT_PENDING`, MD-14, MD-18). Close also
  releases remaining reservations, closes the open MRQ through the port, and requires no open staging list, no
  draft receipt and no open subcontract balance (`p10-10`). `CLOSED` is terminal; reopen with a live (non-rejected) settlement refused.
- **Cost-object resolver after close** refuses issues `409 ORDER_NOT_OPEN` (resolver in `p10-05`).
- **Accounting is a handover** (`FR-657`, `RN-054`): movements carry the standard envelope into
  `whb_accounting_handovers`; no GL account, journal, debit or credit note; labour/overhead recorded only (`OD-43`).
- **Cost sheet**: planned vs actual by component and output, work-centre minutes × rate shown as *recorded, not absorbed*.
