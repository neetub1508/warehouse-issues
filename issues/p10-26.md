## Scope

### Data model (`V562120`)
`whm_tools`, `whm_routing_operation_tools`, `whm_tool_life_entries` (also the booking ↔ tool child rows: partial uk `(confirmation_id, tool_id)`), `whm_maintenance_plans` (+ `planned_duration_minutes`), `whm_maintenance_orders` (+ `planned_start_at`, `planned_duration_minutes`, `cancel_reason`) (DATA-MODEL §2.7.10).

### Rules
- **Tools** (FR-832, `SFL-T1-40`, `-41`, `SFL-GRD-10`, `-12`, `SFL-T4-05`): life unit `SHOTS` / `UNITS` / `HOURS`; routing operations list required tools with `life_per_unit`; a booking names **every** tool used (one life entry per tool — an operation needing a die and a fixture records both; F-R32ME-025); booking refused when a tool is `AT_JOB_WORKER` / `UNDER_MAINTENANCE` / `SCRAPPED` or the booking **would exceed** `life_total` (`409 TOOL_UNAVAILABLE`, `SFL-GRD-10`; F-R32ME-031); alert at `warn_at_percent`; challan dispatch on a `JOB_WORK` challan line of type `TOOLING` (ratified india type, no `MOULDS_DIES_TOOLS` — R46 S1 #662) sets `AT_JOB_WORKER`, its receipt back `AVAILABLE` (`SFL-T1-51`, `-52`; F-R32ME-028).
- **Maintenance** (FR-833, `SFL-T1-42`…`-44`, `SFL-T3-01`, `SFL-T4-04`): plans by calendar days, run hours (from bookings on the machine) or shots (tool life); nightly job raises alerts for due plans; orders `PREVENTIVE` / `BREAKDOWN` with `MNT-` numbers, `planned_start_at` + `planned_duration_minutes`; a **breakdown** order sets the machine `BREAKDOWN` at creation (F-R32ME-022); `IN_PROGRESS` takes the machine / tool out of service (bookings refused `409 MACHINE_UNAVAILABLE` / `TOOL_UNAVAILABLE`); *Cancel* (`SFL-T1-50`, `OPEN` / `IN_PROGRESS`, reason) restores the machine / tool status unless another open order holds it, plan unchanged (F-R32ME-023); completion records downtime minutes with a `DOWNTIME` reason, re-dates the plan, resets tool life when the plan says so; `maintenance.overdue_mode = BLOCK` refuses bookings on an overdue machine `409 MAINTENANCE_OVERDUE` (default `WARN`); spares go out by an ordinary core store issue with cost object `MACHINE`. Planned PM minutes are deducted in the capacity load (`p10-13`, `SFL-T4-04`): each open order's remaining planned minutes in its window, else the plan's next due occurrence — never both (F-R32ME-024).
- **Masters** (`SFL-GRD-31`; F-R32ME-033): a tool or plan referenced by a life entry, routing operation or maintenance order is deactivated, never deleted (`409 MASTER_IN_USE`); `:delete` only while unreferenced.
- No IoT, no OEE, no measuring-instrument calibration (core `p8-20`).
