### `V511321`
- `PRINT_TEMPLATE_KIND` rows (owning module `warehouse`): `GATE_ENTRY_SLIP`, `GATE_PASS`, `MATERIAL_RECEIPT_NOTE`, `MATERIAL_REQUISITION`, `STORE_ISSUE_SLIP`, `STORE_RETURN_NOTE` (GRN kind exists).
- Templates (PDF, A4 portrait unless noted, HTML body, `is_system`): `SYS-GATE-ENTRY` (A5), `SYS-GATE-PASS`, `SYS-MRN`, `SYS-MATERIAL-REQUISITION`, `SYS-STORE-ISSUE` (A5), `SYS-STORE-RETURN` (A5); **`SYS-GRN` version 2** adding the bill block (bill type/no/date, gate entry no., vehicle) and the six quantities (billed, received, excess refused, accepted, rejected, short). Versions are immutable rows (`:168-179` trigger) — v2 is an insert.
- Each kind's data contract in `WhPrintBuiltInDataProvider` (`contracts()`, `load()`, `sample()`), bindings:
  - gate entry: number, direction, purpose, party, vehicle, driver, mobile, transporter, LR, PO nos, bill no/date, e-way bill, entered/exited at, security officer, barcode
  - gate pass: number, kind (**RETURNABLE / NON-RETURNABLE** banner), purpose, party, expected return date, lines (item/description, qty, UoM, approx value, source doc), **signature blocks** maker / approver / security / receiver, returns table for RGP reprints
  - MRN: number, GRN no, supplier, PO, bill no/date, lines (item, lot, billed, received, accepted, rejected, authorised, rate, value), authorised by/at (or *NOT AUTHORISED* watermark when `SUBMITTED`)
  - requisition: number, department, cost object, purpose, requested by, required by, approver, lines (requested, approved, issued)
  - store issue: number, requisition no, department, cost object per line, item, lot, location, qty, receiver acknowledgement block
  - store return: number, issue no, department, lines (qty, condition, reason), submitted by, received by
- States allowed per contract `T2` rows; the data provider refuses other states with `409 PRINT_SUBJECT_STATE_INVALID`.
