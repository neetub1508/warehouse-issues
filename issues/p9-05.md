## Scope
- Tables per contract §0 (`V550040`).
- RFQ issue renders **one print job per invitee** (`TRA-UNR-01`); response tracking; close bids.
- Vendor quotation capture with versions (`supersedes_id`), charges, alternatives, free-of-charge;
  supplier document attachment through platform documents.
- Sealed mode (`warehouse.trade.rfq.sealed_until_due`, default false, `OD-37`): masking happens in the
  **backend response**, not in the page.
- `ComparativeStatementService` computes the matrix (`TRA-T4-01`) including vendor grade (blank until
  p9-12) and contract rate (blank until p9-06); refresh on staleness (`TRA-T4-02`). **One statement per
  RFQ × currency** (`currency_code`, partial uk among statements not `REJECTED`); quotations in another
  currency are shown unranked and are awardable only on their own currency's statement (`TRA-GRD-10`).
- Award editor, split award, reasons; `TradeApprovable` for `CS` with `non_l1_award` condition. Exits:
  rejected → `REJECTED` (terminal, RFQ back to `BIDS_CLOSED`, a new statement may be prepared,
  `TRA-T1-13`); returned → `DRAFT` (`-14`); an input change on a `SUBMITTED` statement returns its request
  (`TAM-T1-08a`). RFQ cancel is allowed from `BIDS_CLOSED` / `EVALUATION` with no approved statement.
- Vendor quotation revise is allowed from `SUBMITTED` **and `EXPIRED`** (a validity extension, `TRA-T1-08`).
- Award targets include an **OPEN PO** (rate fixed, quantity open) as well as FIXED / BLANKET PO and a rate
  contract (`TRA-T4-03`).
- `AwardService.onApproved` drafts targets (`TRA-T4-03`) — FIXED / OPEN / BLANKET PO need p9-07, rate
  contract needs p9-06; a target type whose task has not landed is not offered.
- `TradeRfqJob` (`TRA-T3-01`…`-03`), settings `warehouse.trade.rfq.min_suppliers` (3), `rfq.reminder_days` (2).
- Prints `RFQ`, `COMPARATIVE_STATEMENT`: this task seeds their minimal default templates (FR-615); p9-14 adds final layouts.
- Permissions / menus (*Purchasing — Sourcing*) / grids / scopes / caches (`V551050`, `V551051`).
  `wht_comparative_statements:approve` approves the award — **no `:award` verb** is seeded.
  Notification kind `TRADE_VQ_EXPIRED` and the RFQ reminder kinds (FRD-TRADE §12b).

- Landed price excludes tax (`TRD-06`); charge allocation basis per charge.
- A revised quotation after CS preparation makes the CS stale; submitting a stale CS is refused.
- An alternative item never displaces the RFQ item in rank.
- The CS detail is a matrix — not a `DynamicDataTable`; the list page is.
