## Scope

**Scoped under R32 (2026-10-25).** This file becomes the source for the existing open follow-up **#173** (raised 2026-09-20 from `P2-18`), which had no task file: *"`WhbAccountingEnvelopeV1` is frozen by `RL-002`, so the per-line fields `FR-233` / `WH-SC-156` require — duty status, lot identity, serial identity — and `RF-005`'s exchange rate cannot be added to it. They need a v2 envelope, with a version negotiation the receiving side can accept."* `AHO-OPEN-02` was resolved 2026-10-14 (*X1 quad = contract, account refs advisory; X2 field list adopted, build deferred*): the classification quad stays the contract and `debitAccountRef` / `creditAccountRef` are **advisory only** — v2 carries them as optional hints and the receiver may ignore them. R32 adds what the PRD's accounting rows need on the wire: serials per invoice line (`12A.1-03`), accepted quantity per MRN line (`12A.2-02`), and the source document for document kinds (`P8-23`).

### `WhbAccountingEnvelopeV2` (new record and codec branch; v1 untouched — `AHO-ENV-01`)
- **Header** = v1 header + `sourceDocumentType`, `sourceDocumentId`, `sourceDocumentRef` (document kinds), `currencyCode`, `exchangeRate DECIMAL(19,8)` with `exchangeRateSource` and `exchangeRateDate` (null for base-currency; `RF-005`, `OD-16`).
- **Line** = v1 line + `dutyStatus` (`warehouse-india` bonded / MOOWR status or null), `lotId`/`lotCode`, `serials[]` (id + number, as a child list — text in the payload, no JSONB column), `quantityBilled`, `quantityReceived`, `quantityAccepted`, `quantityAcceptedUnderDeviation`, `quantityRejected` (document kinds; null for movements), `poRef`, `poLineRef`, `soRef`, `soLineRef`, `debitAccountRef` / `creditAccountRef` (**advisory**, `AHO-OPEN-02` X1).
- **Negotiation (`AHO-ENV-13`).** The sink advertises `supportedVersions()` (new default method on `WhbAccountingHandoverSink`, default `{1}`); the dispatcher writes `min(envelope_max_version, max supported)` per kind — a document kind requires v2, so with a v1-only sink it is written `BLOCKED` with `rejection_code = ENVELOPE_VERSION_UNSUPPORTED` and shown on WS-052 (never silently dropped). A stored envelope always replays at its own `envelope_version` (`RL-002`).
- `payload_hash` covers the v2 canonical form (`AHO-ENV-10`).
