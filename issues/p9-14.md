## Scope

### Print documents (FR-615) — final PDF layouts for the nine trade kinds, seeded as **new template versions** in core's `wh_print_templates` / `_versions` (owning-module guard). The minimal default of each kind was seeded by its consuming task (p9-04, -05, -07, -08, -10, -13), so every earlier scenario already prints; this task only supersedes them. A dispatch release has no print of its own (§5 M32)
| Kind | Content (minimum) |
|---|---|
| `PURCHASE_REQUISITION` | number, department, cost object, requester, lines, approvals |
| `RFQ` | one supplier only; lines, required dates, due date, deliver-to, T&C version text |
| `COMPARATIVE_STATEMENT` | the matrix, L1, recommendation, reasons, approvals |
| `PURCHASE_ORDER` | type, version / amendment banner, supplier, Udyam no. when MSME, lines (net price, discount, HSN / tax class *recorded*, "Taxes extra as applicable"), schedule, terms, T&C version |
| `SCHEDULE_RELEASE` | release number, PO reference, lines, dates |
| `CUSTOMER_QUOTATION` | version, validity, lines, customer part no., terms |
| `REGRET_LETTER` | enquiry reference, reason text |
| `SALES_ORDER_ACK` | customer PO ref, committed dates per schedule line, version banner |
| `SALES_RETURN_AUTHORISATION` | lines, reason, return-to site, RMA no. |
Every render is a core print job; reprint flagged (`FR-224` pattern). Company letterhead from platform company data.

### Reports (FR-619), backend queries with grid + export — eight, purchase and sales mirrored

Every money column is shown with its currency and every total is **grouped by currency** — never summed
across currencies (FR-616; `WH-SC-591`). Date-only columns use `formatDateSync`.

| Report (grid id) | Columns (minimum) | Filters |
|---|---|---|
| Open PO register (`wht_rpt_open_po`) | PO no, type, supplier, line item, ordered / released / received / open qty, net price, open value, currency, next due date, ack status | supplier, site, type, buyer, due from/to, currency |
| PR ageing (`wht_rpt_pr_ageing`) | PR no, line, item, department, requester, required date, approved on, age (days), line status, allocated qty | site, department, line status, `ageingOnly` |
| Schedule adherence — purchase (`wht_rpt_schedule_adherence`) | supplier, PO no, schedule line, agreed date / qty, received date / qty, days late, in full (under-tolerance), OTIF flag | supplier, site, period, item category |
| Dispatch adherence — sales (`wht_rpt_dispatch_adherence`) | customer, SO no, schedule line, committed date / qty, shipped date / qty, days late, in full, OTIF flag | customer, dispatch site, period, item category |
| Rate contract expiry (`wht_rpt_contract_expiry`) | side (purchase / sales / price list), contract no, counterparty, valid to, terminates / superseded on, days left, ceiling consumed %, currency | side, counterparty, expiring within n days |
| Open SO register (`wht_rpt_open_so`) | SO no, type, customer, customer PO, line item, ordered / released / shipped / open qty, net price, open value, currency, next committed date, ack status | customer, dispatch site, type, sales exec, due from/to, currency |
| Dispatch backlog (`wht_rpt_dispatch_backlog`) | SO no, schedule line, committed date, due qty, unreleased qty, released-not-shipped qty, ATP shortfall, at risk | customer, dispatch site, horizon, `atRiskOnly` |
| Quotation hit rate (`wht_rpt_quotation_hit_rate`, links WS-300) | sales exec / customer, quotations sent, won, lost, expired, hit rate %, won value, currency | period, customer, sales exec |

Grid identifiers, filter scopes, default columns / filters / sort, tiles and row actions per `trade-reports` §5; `grid_preferences` (both default arrays), permissions
`wht_rpt_<name>:view/export`, menu *Trade Reports* with eight leaves (`V551140`, `V551141`).
