## Scope

### Capacity load (`FR-668`, `MD-09`, R-01)

- **One rule, owned here** (MD-39, R29 F25): [`mfg-mrp.contract.md`](../docs/contracts/mfg-mrp.contract.md) §5.1 and its
  WS-336 row are authoritative (`mfg-production-order` §5.3 cites them). Backend report service: per work centre per
  day, **setup (if not started) + remaining run minutes** of open operations (`OPEN`/`STARTED`) of
  `PLANNED`/`RELEASED`/`IN_PROGRESS` orders, spread evenly over the working days of `[planned_start_date,
  planned_end_date]`, plus (when `includeProposals`) current-run `OPEN` and live `FIRMED` MAKE proposals whose BOM has
  operations over `[start_date, need_date]`, against
  **available minutes × efficiency % × parallel units** on working days (mask), flagging overload (load > 100 %).
- Drill-down from a cell to the orders / proposals contributing.
- **No finite scheduling, no automatic rescheduling, no APS** — the report changes nothing (`WH-SC-659`).

### Registers (WS-337, tabbed)

| Tab | Grid id | Content |
|---|---|---|
| Production register | `whm_register_production` | posted receipts by order, item, lot, good / rejected / scrapped, unit cost |
| WIP by order | `whm_register_wip` | open orders: pool value, absorbed, unabsorbed, by supply model (issue vs staged) |
| Scrap register | `whm_register_scrap` | receipt and operation scrap by reason, normal vs abnormal, value |
| Yield | `whm_register_yield` | good ÷ (good + rejected + scrapped) by item, work centre, period |
| Consumption variance | `whm_register_consumption_variance` | required vs consumed per component, deviation reasons, substitutions |

- All computed in native SQL with `SqlSortBuilder`, LIMIT/OFFSET pagination; nothing aggregated on the page (rule 8).
- Exports a superset of the visible columns; AUDITOR views, never exports (`V698`).
- Date columns: `postingDate` / `period` are `DATE` (`formatDateSync`); timestamps `formatDateWithTimezoneSync`.
