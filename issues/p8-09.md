## Traps
- **Not a demand order** (`STO-D9`, `MRQ-UNR-01`).
- **Record-level department scope in the `WHERE` clause** — a menu filter is not a guard (`P1-18`); out-of-scope ids return 404.
- **Approver rules are service checks** against stored actors; `department_head_id`/`deputy_head_id` from platform `departments`.
- **Reservation only from allocatable status**; the shortfall is computed in SQL, not in the page.
- **No stub hand-off** when trade is off — the action is absent.
- Users shown via the platform user-display helper (never concatenated).
- `required_by_date` is `LocalDate` → `formatDateSync`.
