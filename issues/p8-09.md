## Scope

R27 `RM-015`: demand types include `WORK_ORDER`/`SCRAP`/`SAMPLE`/`JOB_ISSUE` (`V500010:144-152`) but the
demand order follows the shipping ladder and has no department, cost centre, requester or approval. No
cost-centre table exists in platform or accounting-base — only `departments.cost_center VARCHAR(50)`
(platform `V13:15`); accounting's cost centre is a dimension value (`acc_dimension_values`, deferred).

### Seams
- `CostObjectResolver { String type(); ResolvedCostObject resolve(UUID id, UUID companyId); default void assertIssuable(UUID costObjectId, UUID itemId, BigDecimal baseQty) {} default void onIssuePosted(IssueLineFact l) {} default void onReturnPosted(ReturnLineFact l) {} default List<UUID> reservationsFor(UUID costObjectId, UUID itemId) { return List.of(); } }` (`reservationsFor` *amended for MFG MD-16*: non-empty ⇒ approval reserves nothing and the issue consumes those reservations; close/cancel leave them to the owner) — `ResolvedCostObject` carries `ref`, `name`, `departmentId` and **`counterLocationPurpose`** (default `CONSUMED`; MFG's `PRODUCTION_ORDER` returns `PRODUCTION`) (SEAM-M1, SEAM-M2; `STO-D13`). **No `onIssueReversed`** — issues are never reversed (`STO-D11`); MFG's request for it is rejected. — core beans `DEPARTMENT` (platform `departments`, active), `COST_CENTRE`/`MACHINE`/`PROJECT` (`wh_cost_centres` of that kind), `WORK_ORDER` (`wh_work_orders` `RELEASED`/`IN_PROGRESS`, `V510102:184`). `GET /warehouse/stores/cost-objects?type=&search=` serves the cascading dropdown from the resolvers.
- `PurchaseRequisitionHandoff` (optional bean, `ai.warehouse.port.purchase`) — `raise(HandoffCommand) → HandoffRef`, `status(HandoffRef)`.
- `WhMaterialRequisitionPort` — `create`, `cancel`, `close` for MFG (idempotent like `P8-01`).

## Traps
- **Not a demand order** (`STO-D9`, `MRQ-UNR-01`).
- **Record-level department scope in the `WHERE` clause** — a menu filter is not a guard (`P1-18`); out-of-scope ids return 404.
- **Approver rules are service checks** against stored actors; `department_head_id`/`deputy_head_id` from platform `departments`.
- **Reservation only from allocatable status**; the shortfall is computed in SQL, not in the page.
- **No stub hand-off** when trade is off — the action is absent.
- Users shown via the platform user-display helper (never concatenated).
- `required_by_date` is `LocalDate` → `formatDateSync`.
