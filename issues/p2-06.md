## Scope

**`V510035` — WH-25 — `wh_reconciliation_exceptions`.**
`exception_type`, `warehouse_id`, `subject_key_text`, `detected_at`, `owner_user_id`, `age_days`,
`status`, `resolved_at`, `resolution_note`, and **`drift_finding_id` → `whb_position_drift_findings`**
— the one real FK, pointing **down** into base.
Indexes: `idx(status, detected_at)`, `idx(owner_user_id)`.

**Three drift classes, one grid** (`FR-163`):
1. **ledger-versus-position drift** — the nightly `L-4` rebuild disagrees with the cache;
2. **position-versus-allocation drift** — reserved exceeds on-hand for a key;
3. **orphaned reservations** — a reservation whose holder document no longer exists.

`P0-03` built the nightly rebuild and `whb_position_drift_findings` at `V500045`, and `P0-09` built
`whb_reservations` at `V500033`. **This task does not detect drift; it makes drift owned.**
*An exception nobody owns is an exception nobody clears* — hence `owner_user_id`, `age_days` and an
`ageOverDays` filter, and hence Assign and Resolve as first-class actions rather than an alert in a
log.

**WS-098** · `wh_reconciliation_exceptions` · `WAREHOUSE_RECONCILIATION_EXCEPTION` · Service Vehicle
reference. Filters: `exceptionType` select → `status` select · `warehouseId` ·
`ownerUserId` typeahead · **`ageOverDays` select** (a dropdown, so the same filter works on a
handheld) · `detectedFrom`/`detectedTo`. Statistics strip: open by type, oldest age —
**filter-aware, no cache name** (`FR-395`).

This grid is also the answer surface for *"it says insufficient stock and there are 40 on the
shelf"*: `POST /movements/simulate` returns `INSUFFICIENT_STOCK` **with the reservation rows that
caused it**, naming each holder (`WH-SC-186`), and an orphan among them lands here.

**Mobile.** `none` — a controller report. Stated as a decision, per `D-13`/`FR-218`.

## Traps

- **This grid must never be the *only* place drift appears.** `L-4`'s nightly job **fails loudly**
  and alerts; the grid is where the alert is worked, not where it is buried. A silent grid is the
  failure mode `T-019` names.
- **`C-024` is why drift will exist at all.** In `accessories` there is no `@Version` on `StockLevel`,
  no `@Lock` on the repository and **no `CHECK (quantity_on_hand >= 0)` in any migration**; the
  negative guard is a Java read-compare-write and `InventoryStockAdjustmentService.java:63-72`
  contains a comment naming the race it does not defend against. `P0-03` ships all three defences;
  this grid is the evidence that they held.
- **`drift_finding_id` is the only FK and it points down.** `wh_` → `whb_` is legal (`§3.2`);
  `whb_` → `wh_` is not. Do not add a back-reference from `whb_position_drift_findings`.
- **`subject_key_text` is a rendered key, not a serialised object.** No `JSONB` (§1.6). The nine
  position-key members are rendered into a stable string for display and the finding row carries
  the members individually.
- **`age_days` is a stored column maintained by the same job, not a computed `now() - detected_at`
  in the grid SQL** — otherwise sorting and the `ageOverDays` filter cannot use an index.
- **`T-4`** — `detected_at` and `resolved_at` come back from a native query as any of four types.
  Copy `platform/…/service/UserActivityLogQueryService.java:288-307`.
- **`T-6`** — `WAREHOUSE_RECONCILIATION_EXCEPTION` into `COMMON_FILTER_CONFIGS`;
  `detectedFrom`/`detectedTo` are two keys, both listed, both `date`.
