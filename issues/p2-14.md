## This task is on the critical path, and it has zero precedent

```
grep -rli "zpl\|escpos\|dymo" --include="*.java" --include="*.ts" --include="*.tsx" .   # → 0
```

**There is no label or document rendering anywhere in this codebase.** `PP-10` names it as
warehouse's own work, *not* platform's — nothing else in the suite has a use for it and the label
content is warehouse's domain. `DECISIONS.md` §5.1 **`A-2`** moved it into v1 because *a warehouse
that cannot print a pick list, a GRN, a delivery document or a bin label cannot be operated, and
loses to a spreadsheet and a Dymo*; R5 ranks it **ship-blocker #2**.
`IMPLEMENTATION-PLAN.md` §3.5 puts it **on** the critical path, not beside it.

## Traps

- **Everything here is net-new. Budget it as infrastructure, not as a screen.** There is no
  precedent to copy inside this repo, and `T-13` says why a library is not a free answer: **there is
  no per-module npm manifest** — only `platform/frontend/package.json` exists (38 dependencies), so
  a module **cannot add a frontend library**. Rendering is a **backend** concern; the frontend
  requests a rendered artefact.
- **A backend library addition is a `pom.xml` change in `warehouse`/`warehouse-base`,** which is
  legal — the ratchet is *"zero commits to `warehouse-base`"* for **adapters**, not for the app
  (`D-10` corollary).
- **ZPL is a byte protocol with a DPI-dependent coordinate space.** The template's `width_mm` /
  `height_mm` and the printer's DPI are **different facts** and only the first is v1. Store the
  design in millimetres and resolve to dots at render time, or every label is wrong when `P3-08`
  introduces a 300 dpi printer.
- **`P-045`'s date rule applies to every printed date.** A challan date printed from an
  `OffsetDateTime` can print yesterday's date east of UTC. Statutory dates are `DATE`/`LocalDate`.
- **The rendered artefact is a platform `documents` row**, linked with `ON DELETE NO ACTION`
  (`P1-04`'s rule) — a print job whose artefact vanished is not a reprint source.
- **`is_reprint` is set by the *service*, not chosen by the caller.** It is true whenever a
  `(subject_type, subject_id, template_kind)` triple already has a non-void job.
- **Void, never delete** — and the void carries a reason code from the catalogue.
- **`T-11`** — every file is `wh`-prefixed and `/warehouse/printing/*` is `warehouse`'s exclusive
  route root (§0.8).
- **`T-6` / `T-7`** — two filter scopes; `printedFrom`/`printedTo` is a `date` pair (both keys);
  `dropdown.whPrintTemplate` registered in `CacheConfiguration.java`; **no** statistics cache name.
- **Do not build the printer registry here.** `wh_printers` and `wh_print_routing_rules` are
  `V510103`. A `printer_id` FK written now points at a table that does not exist; `printer_name` is
  free text in v1 and the column becomes an FK in `P3-08`.
