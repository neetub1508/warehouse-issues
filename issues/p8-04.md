### Behaviour
- `WhGoodsReceiptLine.billedQuantity()` returns the stored column; `shortQuantity()` = max(billed − received, 0) when billed is set (the PO-based short stays a separate helper used by the `QUANTITY` case).
- Post: refuse undecided excess (`GBM-GRD-05`); post `received − excess_refused` (`GBM-T4-01`); open the `SHORT_SHIPMENT` claim in the same transaction through `WhSupplierClaimService.create` fed by `WhSupplierClaimQueryService.getPrefill` (`:311`) (`GBM-T4-02`); open `EXCESS_OVER_BILL` via `WhReconciliationCaseRecorder.open` (`GBM-T4-03`); set bills `is_live`.
- Reversal: bills `is_live = false`; the draft short claim → `WITHDRAWN` (`GBM-T4-05`).
- **PO matching (TRADE `OD-30`):** `getReceivablePurchaseOrderLines` (`WhGoodsReceiptService.java:300`) and the GRN grid's `poNumber` filter match `po_number` **or** `source_document_ref`; the GRN grid, detail and print show `supplierPoNumber` beside `poNumber`.
- `SYS-GRN` print gains the bill block and the six quantities (template version bump in `P8-12`).

## Traps
- **No debit or credit note, no journal** (`GBM-UNR-01`). `debit_note_ref`/`settlement_ref` stay references.
- **Refused excess never enters stock** — the movement quantity is `received − excess_refused`; the PO roll-up uses the same figure.
- **Approve-excess is maker ≠ checker** through `WhbMakerChecker` against the line's last editor and the GRN creator.
- **The duplicate guard is per supplier per FY on live bills**; a reversed GRN frees its bill number.
- **Free quantity is not excess** — `free_quantity` (scheme) stays excluded from tolerance exactly as today (`:451-509`).
- `invoice_matched` keeps having no writer here; `P5-10` owns it.
- Short-vs-PO `QUANTITY` case and short-vs-bill claim can coexist (`GBM-OPEN-02`).
