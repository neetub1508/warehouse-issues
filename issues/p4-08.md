## Traps

- **`whb_items.epr_category` is a v1 column and this task must not add one.** `warehouse-india` may
  not add a column to a base table (`D-11`). If items are not categorised, the report is empty and
  the fix is a data-quality action plus the `P1-01` master, **not** an `ALTER` from `whin_`.
- **An uncategorised item is a finding, not a zero.** A battery with no `epr_category` silently
  disappears from a statutory return. The report **names the uncategorised items** rather than
  rendering a total that looks complete.
- **The category vocabulary is a seeded catalogue with no `CHECK`** (`D-10`). A fifth EPR regime is
  an insert, not a DROP/ADD — and `widget_definitions.chk_module` in this very codebase has been
  widened by drop-and-add **three times** (`V234:36` → `V276:10` → `V557:18`) and still admits
  neither `warehouse` nor `logistics`.
- **The unit differs per category.** Batteries are reported by weight, tyres by count or weight,
  plastic packaging by weight — so the line carries its **unit**, and the `gst_uqc_code` /
  `unece_rec20_code` mapping on `whb_uoms` (`FR-056`, v1) is where the standard code comes from. A
  return that mixes kilograms and pieces in one total is not filable.
- **Computed from movements, never from balances** (`FR-328`). *Quantity introduced into the market*
  is an outbound aggregation over a past period, which a balance table cannot answer.
- **A filed return is a stored snapshot.** Same discipline as `P4-02` and `P4-03`: re-generating a
  filed period a quarter later must reproduce identical figures.
- **Seed idempotently.** `WHERE NOT EXISTS` on the category rows, or a real unique constraint plus
  `ON CONFLICT` — and note `P-043`'s `T-M11`: if the natural key column is nullable, **NULLs never
  collide and `ON CONFLICT DO NOTHING` can never fire**, so re-running duplicates every row. Both
  v1 adapters' reference-data migrations are re-run on a Flyway retry in `WH-SC-292` for exactly this
  reason.
- **Quantities are `DECIMAL(18,4)`** (`DATA-MODEL.md` §5.1).
- **Export honours filters and sort and carries no audit columns** — this is a report grid.
