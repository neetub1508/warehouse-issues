## Scope

### Data model (`V562020`, DATA-MODEL §2.7.10)
- **`whm_shifts`** — `code` (upper, uk per company + site), `name`, `warehouse_id`, `start_time`, `end_time` (`TIME`, site zone), `break_minutes` (default 0), `is_active`, `status`. Crossing midnight derived (end ≤ start).
- **`whm_operators`** — `user_id` (platform user), `warehouse_id`, `default_shift_id → whm_shifts`, `is_active`, `status`; uk `(user_id, warehouse_id)`.
- **`whm_operator_authorisations`** — `operator_id`, `operation_id → whm_operations` **or** `skill_code_list` + `skill_code` (`WHM_SKILL`), optional `work_centre_id`, `level SMALLINT 1..3`, `valid_from DATE NOT NULL`, `valid_to DATE`, `authorised_by/at`, `note`. Never deleted once referenced by a booking; ended by `valid_to`.
- **`whm_work_centre_shifts`** — `work_centre_id → whm_work_centres`, `shift_id → whm_shifts`, `available_minutes` (≤ shift length − breaks, `422 WORK_CENTRE_SHIFT_INVALID`), `working_days CHAR(7)`; uk `(work_centre_id, shift_id)`. Created here because it needs `whm_shifts`; **this task builds the WS-322 *Shifts* tab** in P10-04's work-centre modal (child editor: shift, available minutes ≤ shift length − breaks, `working_days`) and `422 WORK_CENTRE_SHIFT_INVALID` (FR-785; R46 S1 F3, #595 F1).

### Rules
- Overlap is checked **among the shifts of one work centre** (on a common `working_days` day) on the WS-322 *Shifts* tab, `422 SHIFT_OVERLAP` (`SFL-GRD-01`) — a General shift beside A / B / C is legal; a booking's default shift = the shift **of the booking's work centre** containing its start instant in the site zone, else none (FR-787; R46 S1 F1 DECISION).
- Authorisation names exactly one of operation / skill (`422 AUTHORISATION_SCOPE_REQUIRED`); authoriser ≠ the operator's user (`403 AUTHORISATION_SELF_GRANT`); history kept (FR-788).
- **Authorisation service** `WhmOperatorAuthorisationService.assertAuthorised(userIds, operationId, workCentreId, bookingDate)` — used by `p10-20` at every booking: each crew user must be an active operator of the site with an authorisation valid on the booking date for the operation directly, or for its required skill at ≥ the required level (and for the work centre when the row names one), else `403 OPERATOR_NOT_AUTHORISED` naming user and operation (`SFL-GRD-08`). No check for orders without job cards.
- Operator display uses the platform user-display helper (`{firstName} {lastName} [{employeeCode}] {mobileNumber}`) — never concatenated.
- **Holidays** (FR-785, FR-787; F-R32ME-029): the capacity of a work-centre shift on a date that is a platform holiday of the site's **REGISTERED** branch (else the organisation default; `whb_warehouses` has no `branch_id`) is 0 — read through **one new public core read on `WhWorkingCalendarService`** (the existing private `holidayOn` rule, RESTRICTED closes nothing, `RH-011`; no MFG copy, never the per-employee `HolidayCalendarResolver`; R46 S1 F2); `working_days` keeps the weekdays; `WhmWorkCentreCapacityService.availableMinutes(workCentreId, date)` applies it and `p10-13`'s load report reads it.
- **Masters** (`SFL-GRD-31`; F-R32ME-033): a shift or operator referenced by an authorisation is deactivated (P10-20 adds its booking references, P10-24 its plan-line references to the same check; R46 S1 F4), never deleted (`409 MASTER_IN_USE`); `:delete` only while unreferenced.
- Caches `dropdown.whmShift` registered in `CacheConfiguration.java`, evicted on every write; statistics uncached — one SQL aggregate on the list's filters; `NonFunctionalFoundationsTest:557-559` forbids `statistics.wh*` (R46 S1 #602 F1).

## Traps
- **Authorisation by permission alone** — `whm_job_cards:book` says who may book, not who may weld; both checks apply.
- **`valid_to` compared in UTC** — it is a site-zone date (`formatDateSync`, `dateOnly` filters).
- **Concatenating the user's name fields** — use the platform helper (CLAUDE.md user display).
- **A warehouse holiday table** — not built; holidays are read through core `WhWorkingCalendarService` (P5-10, `V510202`), which reads the platform calendar of the REGISTERED branch (`RH-011`; R46 S1 F2).
