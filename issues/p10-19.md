## Scope

### Data model (`V562050`)

### Rules
- **Request ladder** `ECH-T1-20`…`-32` (`SMR-` number at submit, F-R32ME-032); `SampleRequestPort` declared in core (`ai.warehouse.port.engineering`, optional bean): `open(PortEnvelope, OpenSampleRequestCommand)` (source type / id / line / frozen ref, customer, item or specification, quantity, required date, chargeable, returnable, `blocksProduction`) idempotent on the envelope key, `Optional<SampleRequestStatusView> status(UUID sourceLineId)` and the batch form `Map<UUID, SampleRequestStatusView> statuses(Collection<UUID> sourceLineIds)` for list screens (R46 S1 F5); the view is `requestId`, `requestNumber`, `status` (incl. `WAIVED`), `iterationNo`, `latestFeedback`. No bean when MFG is off — trade's `TSQ-GRD-13` then does not apply (core file only; unblocks P9-19 #648 / P9-21 #650, edge E5).
- **Sample order** (FR-799): `whm_sample_requests:create_order` creates a `SAMPLE` production order for the iteration — trial BOM / routing allowed only here (`422 TRIAL_BOM_ONLY_ON_SAMPLE_ORDER`), drawing revision ≥ `RELEASED_FOR_SAMPLE` (`409 SAMPLE_DRAWING_NOT_RELEASED`); MR → issue → job cards → QC unchanged; output received in stock status `SAMPLE` (non-allocatable) and moved to the *Sample store* location when `p8-22` names one; its cost is reported as sample cost (chargeable / free), never capitalised onto saleable stock.
- **Iteration** (FR-800): internal QC + design check (checker ≠ the order's supervisor, report document); *Next iteration* from `IN_DEVELOPMENT` after a check `FAIL` or `APPROVED_WITH_CHANGES`, and from `REJECTED` (reopen), one open sample order per request (`409 SAMPLE_ORDER_OPEN`; `ECH-T1-27`, F-R32ME-003); *Request dispatch* opens a `WHM_SAMPLE_DISPATCH` approval request (verb `whm_sample_requests:approve_dispatch`, Sales Manager, `SINGLE_LEVEL`; zero levels when `sample.dispatch_approval_required` = `false`, default `true`), approver ≠ requester (`403 SAMPLE_DISPATCH_SELF_APPROVAL`; F-R32ME-007); *Dispatch* (`ECH-T1-28`, `409 SAMPLE_DISPATCH_NOT_APPROVED`) through a core gate pass of purpose `SAMPLE` (an MFG-owned `GATE_PASS_PURPOSE` value seeded in `V562050`) sourced on the iteration by MFG's `WhmSampleIterationGatePassSource` bean, source type `WHM_SAMPLE_ITERATION` (R46 S1 F2) (or the india challan), `courier_name`, `awb_number`, `dispatched_on`, and **moves the stock** (`ECH-T4-09`; F-R32ME-010): **R46 S1 F1 DECISION:** chargeable and free alike post MFG's own movement `SAMPLE_DISPATCH` (with `_REVERSAL`, seeded MFG-owned in `V562050`) out of `SAMPLE` via `WhbStockLedgerWriter.post`, key `SAMPLE_REQUEST:<iterationId>`, recorded as `dispatch_movement_id` (replacing `dispatch_store_issue_id` / `dispatch_shipment_id`); value to the sample cost register (`CST-T4-30`); the charge of a chargeable sample is billed by trade as a non-stock charge on the SO line, a `MANUAL` chargeable request prints `charge_amount` on the dispatch note; feedback `APPROVED` / `APPROVED_WITH_CHANGES` (needs a newer drawing revision, `409 NEW_DRAWING_REVISION_REQUIRED`) / `REJECTED`; returnable samples return through gate entry purpose `SAMPLE_IN` linked to the iteration, received into `SAMPLE` (`ECH-T1-31`); golden-sample retention with location and `retain_until` (`ECH-T1-32`).
- **Approval and gate** (FR-801, `ECH-GRD-10`, `ECH-T4-05`, `-10`; `D-21` item 8; F-R32ME-001, -002): `APPROVED` sets the drawing revision `CUSTOMER_APPROVED`; production release of the drawing and submission of the trial BOM as an ordinary version follow (ECN when a released version exists). The gate tests the line's **mark** (`wh_demand_order_lines.sample_approval_required`), not the request: while no request for the line (or an enquiry-raised one for the same item × customer with a still-current approved revision) is `APPROVED` or `WAIVED`, `p10-05` refuses create / release of a `STANDARD` order for (or covering) the line, any output reservation to it (make-to-stock included) and auto-create (no order, one planner alert, retried on approval), and MFG's `WhmMovementPostGuard` refuses its outbound shipment post — all `409 SAMPLE_APPROVAL_PENDING`. `REJECTED` and `CANCELLED` keep the block. **Waiver** (`ECH-T1-29`, `-30`): reason by `:request_waiver`, approval by another holder of `:approve_waiver` (`403 SAMPLE_WAIVER_SELF_APPROVAL`) → `WAIVED`. The SO line is never refused.
