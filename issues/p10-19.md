## Scope

### Data model (`V562050`)
`whm_sample_requests`, `whm_sample_iterations` (DATA-MODEL §2.7.10, FR-798, FR-800).

### Rules
- **Request ladder** `ECH-T1-20`…`-26`; `SampleRequestPort` declared in core (`ai.warehouse.port.engineering`, optional bean): `open(PortEnvelope, OpenSampleRequestCommand)` (source type / id / line / frozen ref, customer, item or specification, quantity, required date, chargeable, returnable, `blocksProduction`) idempotent on the envelope key, and `status(sourceLineId)`.
- **Sample order** (FR-799): `whm_sample_requests:create_order` creates a `SAMPLE` production order for the iteration — trial BOM / routing allowed only here (`422 TRIAL_BOM_ONLY_ON_SAMPLE_ORDER`), drawing revision ≥ `RELEASED_FOR_SAMPLE` (`409 SAMPLE_DRAWING_NOT_RELEASED`); MR → issue → job cards → QC unchanged; output received in stock status `SAMPLE` (non-allocatable) and moved to the *Sample store* location when `p8-22` names one; its cost is reported as sample cost (chargeable / free), never capitalised onto saleable stock.
- **Iteration** (FR-800): internal QC + design check (checker ≠ the order's supervisor, report document), dispatch through a core gate pass sourced on the iteration (or the india challan), `courier_name`, `awb_number`, `dispatched_on`; dispatch approval by `whm_sample_requests:approve_dispatch` (Sales Manager) when `sample.dispatch_approval_required` (default `true`), ≠ requester (`403 SAMPLE_DISPATCH_SELF_APPROVAL`); feedback `APPROVED` / `APPROVED_WITH_CHANGES` (needs a newer drawing revision, `409 NEW_DRAWING_REVISION_REQUIRED`) / `REJECTED`; returnable samples return through gate entry linked to the iteration; golden-sample retention with location and `retain_until`.
- **Approval and gate** (FR-801): `APPROVED` sets the drawing revision `CUSTOMER_APPROVED`; production release of the drawing and submission of the trial BOM as an ordinary version follow (ECN when a released version exists). `p10-05` refuses create / release of a `STANDARD` order for (or covering) an SO line with an open blocking request `409 SAMPLE_APPROVAL_PENDING`; the SO line is never refused.
