## Why this task exists

A client whose site minimum is Rs 50,000 and whose storage alone is Rs 60,000 still gets a minimum top-up, because storage is billed without a site and counts toward no site's minimum. The client is overbilled and will dispute it.

## Scope

Carry the site on storage billing periods/charges and include them in sumRatedBySite when the setting says so; contract OPEN-3 closed.

## Acceptance

- Storage 60,000 at site S, minimum 50,000, setting true -> no top-up line.
- Setting false -> today's behaviour (top-up 50,000) preserved.
- Company-scope minimum unchanged in both modes.

## Global setting

`WAREHOUSE_3PL_SITE_MINIMUM_INCLUDES_STORAGE` default=true alternatives=false

The default is the recommendation; the alternatives are selectable per install through the settings page.
