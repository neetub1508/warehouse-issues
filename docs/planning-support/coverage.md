Warehouse/base/trade providers own their facts,producer arbitration,policy acceptance,conversion,outbox bootstrap and archive promises. Planning consumes those contracts; it never writes their tables directly. Each source case has one semantic primary leaf and explicit supports in the global ledger. No historical audit observation is automatically refiled as a present defect.

Baseline design-check status is 579 existing violations. New source files must add zero diagnostics; this does not make the unrelated baseline pass. Both independent detailed correction verifications passed at pre-build specification level, with no retained findings.
